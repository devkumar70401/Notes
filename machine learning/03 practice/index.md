# Machine Learning: Practice & Systems

This module covers end-to-end applied machine learning and engineering in production:

- **Data Engineering**: Feature pipelines, data validation, embeddings management, vector databases
- **Training Infrastructure**: Distributed training (DDP, FSDP, DeepSpeed, Megatron-LM), mixed-precision (FP16/BF16)
- **Model Evaluation**: Metrics, offline vs. online evaluation, A/B testing, drift detection
- **Deployment & Acceleration**: Quantization (INT8/INT4, AWQ, GPTQ), model compilation (TensorRT, ONNX Runtime), inference engines (vLLM, TGI)
- **MLOps**: CI/CD pipelines for models, experiment tracking (MLflow, WandB), observability and monitoring
