# Machine Learning: Techniques

This module covers core machine learning model families, algorithms, and training methodologies:

- **Supervised Learning**: Linear models, Logistic Regression, Support Vector Machines (SVMs)
- **Tree-Based Ensembles**: Decision Trees, Random Forests, Gradient Boosted Trees (XGBoost, LightGBM, CatBoost)
- **Unsupervised Learning**: Clustering ($K$-Means, Hierarchical, DBSCAN), Dimensionality Reduction (PCA, SVD, t-SNE, UMAP)
- **Neural Networks & Deep Learning**: Multi-Layer Perceptrons (MLPs), Convolutional Networks (CNNs), Transformers, Attention Mechanisms
